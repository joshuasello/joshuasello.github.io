# Personal Academic Portfolio

Joshua Sello's static academic portfolio, built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/) and deployed through GitHub Pages.

## Requirements

- Node.js 24 or newer
- npm

## Local development

Install dependencies:

```bash
npm install
```

Start Astro's development server:

```bash
npm run dev
```

Open `http://localhost:4321`.

Other useful commands:

| Command | Purpose |
| --- | --- |
| `npm run build` | Type-check and build the production site into `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run astro -- check` | Run Astro's type and content checks |

## Updating the portfolio

Structured homepage content lives in [`src/data/portfolio.ts`](src/data/portfolio.ts):

- `research` contains research themes.
- `publications` contains peer-reviewed work.
- `preprints` contains working papers and public drafts.
- `public_works` contains public-facing articles.
- `planned_research` contains work in preparation and is not currently displayed.
- `updates` contains short news items.

Profile copy and contact links live in [`src/pages/index.astro`](src/pages/index.astro).

Contributor workflow, architecture, and naming conventions are documented in
[`CONTRIBUTING.md`](CONTRIBUTING.md).

## Styling

The site uses Tailwind CSS 4 through the official `@tailwindcss/vite` plugin configured in `astro.config.mjs`.

- Layouts and components use Tailwind utility classes directly.
- `src/styles/global.css` imports Tailwind and contains a small `@apply` layer for Markdown elements generated by Astro content collections.
- Tailwind 4 detects source files automatically, so this project does not need a `tailwind.config` file.

Long-form content uses Astro content collections:

- Articles live in `src/content/articles/`.
- Projects live in `src/content/projects/`.
- Collection schemas live in `src/content.config.ts`.
- The complete authoring guide is in [`docs/CONTENT.md`](docs/CONTENT.md).

Each Markdown filename becomes its URL slug:

```text
src/content/articles/example.md → /articles/example/
src/content/projects/example.md → /projects/example/
```

## GitHub Pages deployment

The workflow at [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) builds and deploys the site whenever `main` is pushed. In the repository's GitHub settings, set **Pages → Source** to **GitHub Actions**.

This is the special `joshuasello.github.io` user repository, so no Astro `base` path is required. The build also includes `public/CNAME` for the existing `joshuasello.com` custom domain.

If the custom domain is removed, update `site` in `astro.config.mjs` to:

```js
site: "https://joshuasello.github.io"
```
